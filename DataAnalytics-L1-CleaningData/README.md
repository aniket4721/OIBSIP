# OIBSIP Task 3 – Data Cleaning

## Project Overview
This project focuses on cleaning and preparing a messy customer dataset using Python and Pandas as part of the Oasis Infobyte Data Analytics Internship.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

## Dataset
The dataset contains customer information such as:
- Customer ID
- Customer Name
- Gender
- Age
- City
- Join Date
- Annual Income
- Spending Score
- Purchase Amount

## Data Cleaning Steps
1. Loaded and inspected the original dataset.
2. Identified missing values.
3. Checked and removed duplicate customer records.
4. Standardised gender and city names.
5. Converted date and numerical columns into correct data types.
6. Corrected invalid numerical values.
7. Filled missing numerical values using the median.
8. Detected outliers using the IQR method.
9. Created boxplots to visualise outliers.
10. Exported the cleaned dataset and quality reports.

## Output Files
- `cleaned_customer_data.csv`
- `outlier_summary.csv`
- `data_quality_report.csv`
